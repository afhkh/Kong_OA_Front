# Kong_OA_FRONT

Kong-OA 办公自动化（OA）系统的前端项目，基于 **Vue 3 + Vite** 构建，配合后端 FastAPI 提供的 `http://127.0.0.1:8080/api/v1` 接口使用。

## 技术栈

| 分类 | 技术 |
| --- | --- |
| 框架 | Vue 3 |
| 构建工具 | Vite |
| 路由 | Vue Router 4 |
| 状态管理 | Pinia |
| UI 组件库 | Element Plus |
| 图表 | ECharts |
| HTTP 请求 | Axios |
| Cookie 管理 | vue-cookies |

## 功能模块

- **登录认证**：用户登录获取凭证（token），存入 cookie。
- **首页 / 仪表盘**：展示服务器性能等信息。
- **系统管理**：系统相关业务接口。
